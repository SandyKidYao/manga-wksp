# manga-wksp

角色素材整理与漫画创作工作区，面向AI辅助创作，不限AI或漫画角色。把角色外观、性格梗、参考图片及出处放在一起，为每篇创作保留独立的输入与版本记录。

- [角色库](characters/INDEX.md)：每个角色的README列素材来源，每个分支的PROFILE合并外观与性格设定。
- [工作指引](AGENTS.md)：素材搜集、更新、分支管理与创作检查规范。

## 目录

```text
characters/
  角色/README.md                 素材引用清单
  角色/分支-vN/PROFILE.md         外观、性格与证据边界
  角色/分支-vN/images/            本地参考图
  _sources/、_shared/             本地原始资料与多人参考
comics/日期-英文短名/             每篇独立创作，仅本地
.local/                          私人工作与校验记录，仅本地
AGENTS.md                        工作指引
LICENSE                          项目原创内容的MIT许可
```

## 使用与创作

1. 从角色库选择具体分支，实际查看图片和PROFILE，确认常规／Q版差异、采用状态与来源可信程度。
2. 先讨论并定稿脚本，再在独立的comics目录中用CAST记录人物与道具，inputs保存实际采用的图片和文字快照。
3. 使用imagegen生成或修改插画，在work保留实际提示词和工作图。修改后同步完整脚本，旧版本另存。
4. 逐格检查所有人物、道具、动作连续性、阅读顺序和中文；output/vN保存图、当时脚本和QA，作品README指向当前版本。

## 搜集与更新素材

先查已有清单、来源URL与内容哈希，避免重复下载。每个素材记录本地路径、内容／比例、原作者（已知时）、原作与转载URL、获取日期、采用状态和授权依据或未知项；区分官方、二创、单作者设定与未核实内容。页面无法访问时如实记录，不猜作者、日期或许可。

更新时同步角色README和PROFILE，区分不同形象分支，保留常规与Q版的衣装差异。实质性变化使用新文件名或分支版本，不覆盖历史，不改变已有作品锁定的inputs。外部原文快照保持原样，在旁补充说明；完成后检查相对链接。详细规范见[AGENTS.md](AGENTS.md)。

## Git发布范围

默认纳入版本控制的是自行整理的文档、来源清单和设定摘要。**comics整目录默认被.gitignore排除，仅供本地创作，不随仓库同步发布。**

参考图片、多人共享图、原始投稿JSON、外部全文快照及.local私人记录也默认仅留本地，环境密钥、缓存和系统杂项同样忽略。角色文档中的图片／sources链接可能指向不随Git提供的本地资产；公开来源URL用于溯源，不能把链接存在理解为素材会随仓库提供。

公开前核对文件范围、隐私、第三方许可及必要署名；不要自动解除素材忽略规则或发布私人创作。

记录来源不等于获得再分发许可。授权未知的素材默认仅本地保留；即便有CC0或CC BY-NC-SA等声明，也应核对权利链、署名与衍生条件，再决定是否另行分发。
